# Ideas

Space for capturing and managing product ideas before they get promoted into specs.

## How to use
1. Add a new markdown file per idea in this folder.
2. Tag the relevant area (app, web, or server) in the idea's front matter so it's easy to filter.
3. Capture the problem, the proposed solution, and any open questions.
4. Once an idea is accepted and scoped, promote it into the relevant docs section.

## Idea template
```markdown
# <Idea title>

**Status:** draft | exploring | accepted | parked
**Area:** app | web | server

## Problem
What user or business problem does this solve?

## Proposal
The proposed solution at a high level.

## Open questions
- ...

## Notes
```
